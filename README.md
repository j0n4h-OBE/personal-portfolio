# Personal Portfolio

This repository contains a personal portfolio website built with HTML and CSS. It includes sections for a home introduction, about me details, technical skills, featured projects, and a contact form.

## Project Structure

- `index.html` – main page structure and content
- `style.css` – styling, layout rules, responsiveness, and hover effects
- `images/` – local SVG assets used for the profile and project previews

## Features

- Responsive single-page portfolio layout
- Semantic HTML5 sections and accessibility-friendly markup
- Modern styling with gradients, cards, and hover effects
- Contact form section and project showcases
- GitHub Pages-ready static site

## Local Preview

Open `index.html` directly in a browser, or serve the project locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

To publish this site on GitHub Pages:

1. Push this repository to GitHub.
2. In the repository settings, navigate to **Pages**.
3. Select the **Deploy from a branch** option.
4. Choose the `main` branch and `/root` folder.
5. Save the settings and wait for the site to be published.
